# Canvas 特效训练营

从画一个方块，到写一个星云着色器。**35 课**由浅入深，覆盖 **Canvas 2D → WebGL**，最终汇入「音画黑洞」毕业设计。

课程以「**参数实验室**」形式呈现：每个 API 的参数都是滑块/颜色/开关，拖动即时生效、代码同步变化，边玩边学。

## 快速开始

无需服务器、无需构建、不依赖 CDN——**纯静态文件，双击即可运行**（音频、图片、着色器均以 base64 内嵌，`file://` 协议下完全可用）。

- 打开 [index.html](index.html) 查看课程导航（35 课）
- 打开 [player.html](player.html) 直接进播放器，`?lesson=NN-xxx.js` 切换课程

## 课程形态：参数实验室

| 能力 | 说明 |
|---|---|
| 实时调参 | 每个 API 参数都是滑块/颜色/开关，拖动画面即时变化 |
| 代码同步 | 底部代码片段随参数实时更新，改动值高亮闪烁 |
| 逐步拆解 | 播放动画，一步步看清每个 API 的职责 |
| 完整代码 | 一键查看/复制当前课的**独立可运行 HTML**（CodeMirror 编辑器展示） |
| 挑战 | 每课结尾可调参达成目标效果 |

## 文件结构

```
├── index.html           # 课程导航首页
├── player.html          # 播放器（唯一运行入口）
├── player.js            # 播放器引擎（2D/WebGL 双支持 + 完整代码生成）
├── COURSE.md            # 完整课程大纲（每课知识点/产出/挑战）
├── lessons/             # 35 个课程配置（每课一个 window.LESSON）
├── lib/codemirror/      # 本地打包的 CodeMirror（完整代码编辑器展示）
├── tools/audit.js       # 课程审计脚本（校验代码片段/参数反馈）
├── music-data.js        # 内嵌音频（base64）
├── image-data.js        # 内嵌背景图（base64，像素课用）
├── music.m4a            # 音频源文件
└── bg.webp              # 背景图源文件
```

## 两条主线

1. **Canvas 2D**（CPU 绘制）：基础绘制 → 图形数学 → 动画交互 → 音频可视化 → 粒子 → 像素处理 → 物理与流体
2. **WebGL**（GPU 管线）：渲染管线 → GLSL → SDF / 噪声 FBM → 解剖重写 master 分支的星云着色器

> WebGL 阶段会反向拆解 `master` 分支（Cocos Creator 项目）里 `assets/shader/starField.effect`
> 的星云着色器，作为毕业大作业（课 33-35）。

## 新增课程

1. 在 `lessons/` 新建 `NN-xxx.js`，参照 `01-hello-canvas.js` 声明 `window.LESSON`（字段说明见 COURSE.md「参数实验室课程格式」）
2. 在 `player.js` 的 `MANIFEST` 里登记，即可出现在播放器导航（上一课/下一课/下拉）
3. 更新 `index.html` 导航、`README.md` 总览与 `COURSE.md` 状态
4. 跑 `node tools/audit.js` 校验（代码片段占位符绑定 + 参数反馈完整性）
